Set up Joule

1 · Add your provider key

Paste your OpenAI, Anthropic or Groq key. Joule holds it server-side, encrypted, and uses it to make your model calls — it is never written to logs and never sent back to your browser. We verify it now with a free /models check so you don't discover a typo in production.

2 · Get your Joule key + endpoint

This is the key your app uses instead of your provider key. Point any OpenAI SDK at Joule by changing two lines — everything else in your code stays the same.
⚠️ Copy this now — for your security it is stored only as a hash and will never be shown again. You can create another any time.
